GitHub Pages setup

1. Extract your original IELTS_Study project.
2. Put this index.html in the ROOT of the project (same level as Listening, Reading, Speaking, Writing folders).
3. Upload the extracted folders/files to a GitHub repository. Do NOT upload only the ZIP if you want GitHub Pages to serve the site.
4. Repository Settings → Pages → Deploy from a branch → main → /(root) → Save.
5. The root structure should look like:

index.html
Listening/
Reading/
Speaking/
Writing/

Important:
- Folder names and file names are case-sensitive on GitHub Pages.
- Do not rename the existing 17 practice HTML files unless you also update index.html.
